# DeepCore 2

## Download and assemble

The release archive is split into four parts. Download all four files from the [latest release](../../releases/latest) into one folder.

Download [ASSEMBLE_ARCHIVE.cmd](ASSEMBLE_ARCHIVE.cmd) into that same folder and double-click it. The script creates `DeepCore_2_20260824.zip`.

Extract the resulting ZIP, then double-click `START_DEEPCORE_2.bat` inside the extracted `DeepCore_2_20260824` folder.
